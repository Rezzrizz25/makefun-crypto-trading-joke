One line, under 200 characters, about crypto and trading life — entered in the [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on make.fun. A judge model reads entries two at a time and picks the funniest.

> I bought the top, sold the bottom, and now I stare at the chart like it owes me an apology — the group chat calls it a strategy.

## Run it

```sh
node main.ts
```

This writes the single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), enforcing the 1–199 character, single-line, non-blank gate.
